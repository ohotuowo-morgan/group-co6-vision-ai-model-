# Dog vs Wolf AI Classifier - Group CO6

This repository contains a deep learning computer vision web application designed to classify images of dogs and wolves. 

The model utilizes **transfer learning** via a fine-tuned **MobileNetV3** Convolutional Neural Network (CNN). The frontend is powered by **Streamlit**, providing a clean, responsive UI that processes user uploads, reshapes inputs to 128x128 pixels, and outputs real-time confidence predictions.

### 🛠️ Tech Stack
* **Deep Learning Framework:** TensorFlow / Keras
* **Base Model:** MobileNetV3 (Small)
* **Frontend UI:** Streamlit
* **Data Processing:** NumPy & Pillow (PIL)
